## [0.5.0] - 2026-08-21

### Added

- Public repository governance, contribution, security, and trademark policies.
- Issue and pull request templates for public collaboration.
- A bilingual README, generated architecture overview, and licensed ViDoRe sample corpus.
- Fixed-digest Linux and Windows installers with backup, upgrade, rollback, recovery, and Codex Skill lifecycle commands.
- Independent encrypted Provider profiles for MinerU, Embedding, Reranker, and optional LLM roles.
- Retrieval, bounded Source Context, and PDF page-level verification routes for external AI agents.

### Changed

- Python package metadata now points to the canonical public repository.
- Release builds now publish an isolated `traceable-rag-public` multi-architecture image only after deterministic acceptance, SBOM generation, and vulnerability gates pass.
